## C++ Quiz Game
A simple interactive quiz game made using C++.
## Features
- Player name input
- Multiple choice questions
- Score tracking
- 3 lives system
- Instant answer feedback
- Final score display
- Replay option
- Functions for better code organization
## Concepts Used
- C++ functions
- Variables
- Conditional statements
- Loops
- User input/output
- Pass by reference
- Strings
- Basic program structure
