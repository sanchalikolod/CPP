## Student Management System
A console-based Student Management System developed using C++.
## Features
- Add student records
- Display all student records
- Search for a student using roll number
- Update student details
- Delete student records
- Store student records permanently using file handling
- Menu-driven interface
## Student Details
The system stores:
- Roll Number
- Name
- Age
- Course
- Marks
## Concepts Used
- C++ Structures
- Arrays
- Functions
- Loops
- Conditional Statements
- File Handling
## Author
C++ learning project focused on practicing file handling, structures and functions
